# pi-custom-public

The public release-readiness site and future audited distribution of the pi-custom toolkit.

> The toolkit is not yet ready for public release. This repository currently contains only the read-only release proof sheet. Components will be added gradually after privacy, security, licensing, provenance, and portability review.

## Release proof

The static site is stored in [`docs/`](docs/) and its version-controlled task ledger is [`docs/release-tasks.json`](docs/release-tasks.json).

Task updates are made through Git commits and pull requests; the browser is read-only.
